# Bio & Profile Templates

## Positioning one-liner formulas

1. **"I help {X} do/achieve {Y} without {Z}"** — the canonical creator formula. "I help coaches book 10 clients/mo without paid ads."
2. **"{Y} for {X}"** — compressed variant. "Notion systems for agency owners."
3. **"{what_I_do} in {unique_way}"** — "Website design done in two weeks."
4. **"{who_I_serve} + {transformation}"** — "Empowering solopreneurs to scale without burnout."
5. **"{role} + {specialty} + {differentiator}"** — safest, zero wordplay. "SEO expert for B2B SaaS companies."
6. **"{action_verb} + {benefit} + for {audience}"** — "Simplifying social media for busy entrepreneurs."
7. **"{identity} + {value_prop}"** — "Legal mind, coaching heart."

## Universal profile checklist

- [ ] Name field contains the {keyword} people search, not just the name (name field is search-indexed)
- [ ] One-liner from above in line 1–2 of bio
- [ ] Proof line: "Featured in {press}" / "{N} clients" / "{result} in {timeframe}"
- [ ] One CTA + one link ("👇 Free {asset}")
- [ ] Pinned post = best proof asset
- [ ] Banner/avatar carry the {brand_asset}s (consistent color, face for founders)
- [ ] Niche is guessable in 5 seconds (grunt test)

## LinkedIn

- **Headline (220 chars):** "{role} | {3_skills} | {credibility_line_with_number} | {what_you_want}"
  e.g. "Senior Software Engineer | React, Node, AWS | I ship fintech products used by 2M+ users | Open to staff-level roles."
- **About opener (above the fold):** "I help {who} do {what} by {how}. In the last {timeframe} I've {specific_outcome_with_number}." Then 3–4 short paragraphs + CTA.
- Banner 1584×396: specialty + CTA. Featured: 3 items (best artifact, case study, recent hit). Experience bullets: verb → scope → outcome ("Rebuilt checkout flow; cut abandonment 14%"). Pin the top 3 skills for the role you *want*; 2+ recommendations; post weekly, comment daily.

## Instagram / TikTok (≤150 chars)

Line 1 (name field): {searchable_keyword}
Line 2: one-liner formula
Line 3: proof ("Featured in {X}" / "{N}+ students")
Line 4: CTA + link ("👇 {free_asset}")

## X

"{what/for whom} | {proof_point_with_number} | {personality_hook_or_current_project} | {cta_to_pinned/newsletter}"

## YouTube

Channel tagline = one-liner formula; banner states the value prop + upload cadence; channel trailer = 30–60s PPP intro (preview/proof/payoff); playlists named by search queries.
