# Content Calendar & Cadence System

## Pillar architecture

- 3–5 pillars = recurring themes at the intersection of {audience} needs × brand expertise. Start with 3; expand to 4–5 only after 60+ days of data; never exceed 5.
- Every post ladders to a pillar. Track per-pillar KPIs: educational → saves/shares; community → replies/UGC; authority/proof → profile visits, inbound; promotional → clicks/DMs; entertaining → reach/new followers.

## Mix ratios (defaults)

- **By intent:** 30–40% educational · 20% community/conversation · 20% entertaining · 15–20% proof/authority · promotional capped at 10–15%.
- **Planned vs reactive:** 80% planned pillar content / 20% reactive (trends within the 24–48h window, replies-as-content).
- **Brand vs activation lens (from intelligence/01):** ≈60% brand-building (emotional, broad, no hard CTA) / 40% activation (offer, lead magnet, launch) over rolling quarters.
- **Proven vs experimental:** 70% proven formats / 20% iterations / 10% experiments.

## Weekly theme skeleton

| Day | Slot |
|---|---|
| Mon | Education (how-to / checklist) |
| Tue | Community or product |
| Wed | Proof (results / testimonial / case) |
| Thu | Education |
| Fri | Industry opinion / contrarian |
| Sat/Sun | Light community / Q&A / reshare |

**Template:** "Week {N}: Mon {education: topic}, Tue {community}, Wed {proof_asset}, Thu {education}, Fri {opinion}, weekend {qa}."

## The content matrix (pillars × formats)

Rows = pillars; columns = formats (carousel, short video, text post, thread, live/story). Each cell = a recurring slot. **One strong idea per row per week → repurposed across every format column** (see playbooks/11 loop 4). Calendar sheet columns: date · platform · pillar · topic · format · hook · CTA · status · owner.

## Batching workflow (4 sessions, never daily creation)

1. Writing session — all captions + hooks + CTAs for the week/month.
2. Recording session — all video in one block (same setup, multiple outfits/angles).
3. Design session — all graphics/carousels.
4. Edit & schedule session.

## 30-day new-account launch calendar

- **Week 1 — Establish:** all education; plant the niche flag; bio finalized (templates/26); pinned intro/proof post. Daily engagement routine begins (playbooks/11 loop 1) and never stops.
- **Week 2 — Add proof:** introduce results/testimonial posts + first personal story. Watch which Week-1 format earns saves/retention.
- **Week 3 — Engage:** add community formats (questions, reply-to-comment content, duets/stitches); double down on the Week-1/2 winner.
- **Week 4 — Soft promo:** first promotional post (≤10–15% of total): lead magnet with comment-{keyword} CTA → DM → email capture.
- Throughout: weekly skeleton above; 4–7 posts/week; 30 min/day engagement given; no external links in posts.

## Repurposing chain (standard weekly run)

One pillar asset (long video / article / podcast) →
1. 3–7 vertical clips (new hook per clip) → TikTok/Reels/Shorts
2. 1 carousel (key steps) → Instagram + LinkedIn document
3. 1 thread → X
4. 2–3 text posts (single insights) → LinkedIn/X
5. 1 newsletter section → email
6. Quote graphics / stills → stories, Pinterest
Engagement data on the pieces selects next week's pillar topic.
