# Caption Structures

## Truncation points — the hook must fit BEFORE the cutoff

| Platform | "See more" cutoff | Max | Research-backed ideal |
|---|---|---|---|
| Instagram | ~125 chars | 2,200 | 138–150 chars for reach; 800–1,500 for educational carousels (saves/shares) |
| LinkedIn | ~210 chars | 3,000 | 1,200–1,600 chars (dwell time); 8–12 line breaks |
| TikTok | — | 2,200 | 50–150 chars; longer only to carry SEO keywords |
| X | — | 280 (25K Premium) | 71–100 chars |
| Facebook | ~477 desktop | 63,206 | 40–80 chars (under-80 ≈ +66% engagement [reported]) |
| Pinterest | — | 500 (description) | 220–232 chars, ≤5 keywords |

## Universal caption skeleton

```
{hook line — fits above the fold; from templates/20}

{context: 1–2 short lines}

{value: 3–5 one-line points, or mini-story with But/Therefore beats}

{payoff / lesson line}

{ONE CTA — from templates/25}
{hashtags per rules below}
```

**Rules:** one idea per line; blank line between thoughts; 8th-grade reading level; first line must work standalone; never open with an @mention or a link; keywords written into sentences (captions are search-indexed everywhere now).

## Hashtag rules (2026)

| Platform | Count | Placement |
|---|---|---|
| Instagram | 1–5 precise, niche | Caption end or first comment |
| TikTok | 3–5 | Caption — still matters for discovery |
| LinkedIn | 0–3 industry-specific | End (3–5 slightly reduces reach; 6+ hurts) |
| X | 0–1 | Inline; 3+ risks spam classification (~−40% reach) |
| Facebook | 0–2 | Minimal impact |
| Pinterest | 0 | Keywords in fields do the work |

## Alt text & accessibility

Write alt text everywhere it exists (Instagram, LinkedIn, Pinterest, X): it's an SEO surface (Pinterest: +25% impressions, +123% outbound clicks [measured]) and an accessibility requirement. Describe the image with {keyword}s naturally.
