# Post Templates by Platform

## LinkedIn — 8 templates

1. **Hook–Story–CTA (personal story arc):**
   "{hook <15 words: surprise/contrast/vulnerability}
   {narrative: anecdote or client win with a turning point and metrics}
   {lesson in one line}
   {question_to_reader}"
2. **Contrarian take:** "{contrarian_claim stated flat}. {acknowledge mainstream view}. {3–5 reasons/data points, one line each}. 'What am I missing?'"
3. **Listicle:** "{N} {things} that {outcome}: 1) … 2) … (one line each, blank line between). Close: 'Which would you add?'"
4. **Case-study breakdown:** "Lead with the most impressive result ({x} → {y} in {timeframe}) → 3–5 specific actions that caused it → the initial challenge (credibility) → takeaway question." Specificity is the asset.
5. **Vulnerability/failure post:** specific failure (never vague) → exact actions taken → connect struggle to outcome. Resolved struggles outperform unsolved ones.
6. **Question post:** brief observation → open question (never yes/no) → your own answer first → reply hard in the first hours.
7. **Micro-insight (daily-cadence friendly):** one counterintuitive idea → 1–2 sentences of consequence → reflective close.
8. **Document/carousel (PDF):** Slide 1 curiosity-gap title ("{N} Mistakes in {topic}") → one idea per slide, ≤60 words, ≥24pt, progress numbers → final slide single CTA (comment {keyword} / follow). 5–15 slides at 1080×1350. Every swipe is a micro-commitment the algorithm counts.

**LinkedIn formatting rules:** hook fits in first ~140–210 chars; 800–1,500 chars total; 8–12 line breaks; no external links in body (comments instead); 0–3 hashtags at end; personal profile > company page (5–8× engagement).

## X — single posts & threads

**Hook tweet — 4-part formula:** ① Bold statement ② Tension (pain) ③ Twist (unexpected angle) ④ Credibility (receipts: numbers, results).

**Four hook archetypes:**
- Specificity: "I {result_with_exact_numbers} in {timeframe}. Here's the {N}-step system:"
- Question: "Why do {surprising_observation}? The answer isn't what you think."
- Bold claim: "{controversial_statement}. Here's the proof:"
- Curiosity gap: "…Most people don't know about #{N}:"

**Thread architecture (10-tweet skeleton):**
T1 hook (the ad for the thread — strongest claim) → T2 context → T3 framework promise ("5 tactics:") → T4–T7 one point per tweet + example, cliffhanger every 1–2 tweets → T8 synthesis → T9 soft CTA ("If this helped…") → T10 hard CTA ("RT the first tweet" / "Follow {handle} for {niche}").

**Rules:** 71–100 chars ideal for single posts; structure for bookmarks (saveable lists, frameworks, data); first video frame = thumbnail; links in the reply, never the post; reply to replies within 2–3h (reply-conversation ≈ 150× a like); 3+ hashtags risks spam classification — use 0–1.

## Instagram carousel — slide-by-slide

- **Slide 1 (hook):** earn the swipe — specific promise, number or claim; high contrast; swipe cue. Templates: "{N} {things} that {result}" / "{contrarian_claim}" / "How to {outcome} without {pain}".
- **Slides 2–8 (value):** ONE self-contained idea + one visual per slide; progress markers ("3/7"); one contrarian/surprising slide mid-carousel to re-hook.
- **Slides 9–10 (CTA):** save / share / comment {keyword}.
- **Design rules:** 7–10 slides ideal; ≤2 typefaces; one accent color; identical margins; 4:5 (1080×1350) throughout; caption follows templates/27.
- **Health metrics:** 60–75% slide-1→2 swipe-through; 25–40% completion; 1.5–3% save rate = strong.

## TikTok — 12 format concepts

| Format | Structure | Use for |
|---|---|---|
| Tutorial | Result upfront → numbered steps <60s | Education; earns saves |
| Storytime | Hook line → situation → conflict → resolution (But/Therefore) | Personal narrative |
| POV | "POV: you're {role}" text → scene from viewer's perspective | Relatability |
| Before/After | Opening state → quick-cut transformation | Results proof; drives shares |
| Myth-busting | Name the misconception → why false → correct info | Authority; comment bait |
| Day-in-the-life | Chronological montage, raw moments | Humanization |
| Reply-to-comment | Pin question on screen → detailed answer | Community signal; infinite ideas |
| Green-screen | Talk over image/article | Hot takes, explainers |
| Duet/Stitch | React to or complete a viral clip | Borrow audiences |
| GRWM | Get-ready process + voiceover story | Lifestyle niches |
| Trend test | "I tried {trending_hack}" → honest result | Fails outperform successes on comments |
| Unpopular opinion | Contrarian take + context | Argument-driven comments |

**Rules:** hook by 1.5s in text AND voice; keywords spoken in first 2–3s (spoken > written for TikTok SEO); UGC-style over polish; 60%+ watch with sound on.

## Facebook & Pinterest quick templates

- **Facebook:** copy 1–80 chars; question or bold statement + Reel/album; conversation-bait (5+ word comments weigh ~3×); Groups post: value story + question, no links.
- **Pinterest pin:** 1000×1500; benefit text overlay ("{N} {topic} ideas that {outcome}"); title {keyword-front-loaded, ≤40 chars visible}; description 220–232 chars, ≤5 keywords, natural language; alt text always.
